『影響力の正体』30日チャレンジ - PWA版
========================================

■ 中身
- index.html   ... アプリ本体（進捗はスマホ内に保存されます）
- manifest.json ... ホーム画面追加のための設定ファイル
- sw.js         ... オフラインでも開けるようにするservice worker
- icons/        ... ホーム画面に表示されるアイコン画像

■ 公開してホーム画面に追加する手順
ホーム画面への追加には「HTTPSでの配信」が必要です（ローカルファイルを
直接開くだけでは追加ボタンが出ません）。以下のどれかが簡単でおすすめです。

【方法A：GitHub Pages（無料・おすすめ）】
1. GitHubに新しいリポジトリを作る
2. このフォルダの中身（index.html, manifest.json, sw.js, icons/）を
   そのままアップロード
3. リポジトリの Settings → Pages で公開を有効化
4. 発行されたURL（例: https://ユーザー名.github.io/リポジトリ名/）に
   スマホでアクセス

【方法B：Netlify / Vercel（もっと簡単）】
1. netlify.com または vercel.com にアクセスしてアカウント作成
2. このフォルダをそのままドラッグ＆ドロップでアップロード
3. 発行されたURLにスマホでアクセス

■ スマホでホーム画面に追加する
- iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」
- Android（Chrome）: 右上のメニュー → 「ホーム画面に追加」

追加後はアイコンをタップするだけで、アプリのように全画面で開きます。

■ 注意
- 進捗（チェックの状態）はブラウザのlocalStorageに保存されます。
  スマホ本体やブラウザのデータを消去すると、進捗もリセットされます。
- 複数の端末で進捗を共有することはできません（端末ごとに保存されます）。

■ 更新した内容が反映されないとき
このアプリはオフラインでも開けるよう、sw.js（サービスワーカー）が
ページをキャッシュしています。GitHub側のファイルを差し替えても、
スマホ側がその変更に気づかず、古い画面のまま表示され続けることが
あります。

- index.html だけでなく、sw.js も必ずセットで差し替えてください
  （sw.jsの中身が一切変わらないと、スマホはアプリの更新自体に
  気づけません）
- 差し替えたあとは、ホーム画面のアプリをスワイプで完全に閉じてから
  もう一度開いてください（ブラウザでの再読み込みだけでは反映され
  ないことがあります）
- それでも直らない場合は、ブラウザの設定からサイトデータ／キャッシュ
  を削除してから開き直してください
